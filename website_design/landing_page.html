Three Steps to Mastery

01

Install

Run the bootstrap command to initialize the ven binary on your system path.

curl https://get.ven.sh | sh
02

Init

Initialize ven in your project directory to create a secure environment lock.

ven init --all
03

Code

Your versions are locked and ready. Start building without conflict worries.

ven start
