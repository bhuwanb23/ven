Install Ven

The high-performance version manager. Zero dependencies. Native binary. One command to rule them all.

Install Command
curl -fsSL https://ven.sh/install.sh | sh

Installs to ~/.ven/bin/ven and adds to PATH automatically.

account_tree What Gets Installed

Next Steps

1

Initialize Shell

Refresh your environment to load the new PATH variables.

source ~/.zshrc # or ~/.bashrc
2

Install a Version

Add your first managed tool using the high-speed engine.

ven install node@latest
3

Switch Context

Activate the version in your current terminal session.

ven use node@20

Corporate & Portable

Strict environment? Ven can run entirely from a local folder without root access or modifications to your global shell config. Perfect for air-gapped or restricted CI environments.

VEN_HOME="./.ven" ./ven-portable install

Frequently Asked

Why is it so fast?

Ven is written in pure Rust with a custom-built parallel downloader. We bypass overhead by symlinking directly to binary paths.

Does it support Windows?

Yes. We provide a native PowerShell installer and a portable EXE for corporate environments.

What happens to NVM?

Ven can coexist with NVM, but we recommend migrating to avoid PATH conflicts and improve shell startup time.

Is there a GUI?

Ven is strictly CLI-first. We believe in terminal mastery and scriptability for all developers.
