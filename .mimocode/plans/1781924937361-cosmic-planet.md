# Fix: PHP Version Listing Only Shows One Version

## Problem
`ven install php` only shows one version because `fetch_php_release_versions()` scrapes `https://windows.php.net/download/` which is a JavaScript-driven page that only renders download links for the currently selected version.

## Solution
Scrape the archives directory listing at `https://downloads.php.net/~windows/releases/archives/` instead. This is a static Apache directory listing with ALL PHP versions as `<a href="php-X.Y.Z-...">` links.

## File to Modify
`src/core/php_install.rs` — lines 116-144, rewrite `fetch_php_release_versions()`

## Implementation

```rust
pub fn fetch_php_release_versions() -> Result<Vec<String>> {
    // Fetch the archives directory listing (static HTML, all versions)
    let resp = Client::new()
        .get("https://downloads.php.net/~windows/releases/archives/")
        .send()
        .context("Cannot reach downloads.php.net")?
        .error_for_status()?;
    
    let body = resp.text().context("Failed to read PHP archives page")?;
    
    // Extract version numbers from <a href="php-X.Y.Z-...">
    let mut versions = Vec::new();
    for line in body.lines() {
        if let Some(start) = line.find("href=\"php-") {
            let after_php = &line[start + 10..]; // skip "href=\"php-"
            if let Some(end) = after_php.find('-') {
                let ver = &after_php[..end];
                // Only include 8.x+ versions (filter out old 5.x, 7.x)
                if ver.starts_with("8.") && ver.chars().all(|c| c.is_ascii_digit() || c == '.') {
                    versions.push(ver.to_string());
                }
            }
        }
    }
    
    versions.sort_by(|a, b| version_cmp_parts(b, a));
    versions.dedup();
    Ok(versions)
}
```
