### How PHP Works

1. **Install**: Downloads ZIP from `windows.php.net`, extracts to `~/.ven/php/<version>/`
2. **Activate**: On `cd` into project with `php = "8.3"` in ven.toml, sets PATH + PHPRC
3. **Use**: `php --version` works automatically
4. **Delete**: `ven delete php 8.5.7` removes the version

### Example Workflow

```bash
# Install PHP
ven install php 8.3

# Create project
mkdir my-project && cd my-project
ven init  # or manually create ven.toml

# ven.toml
[runtime]
php = "8.3"

# Use PHP (auto-activated on cd)
php --version  # Uses PHP 8.3.x

# Check status
ven status  # Shows ✓ php 8.3 (8.3.6)

# Delete when done
ven delete php 8.3.6
```

PHP is **fully functional** for the core use case: installing, managing, and using PHP versions per-project. The advanced features (Composer integration, lockfile) are optional enhancements that can be added later.
