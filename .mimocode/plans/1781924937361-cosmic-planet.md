# Plan: Add PHP Support to ven

## Overview
Add PHP as the 9th language supported by ven. PHP is the most requested language (342 votes on website) and distributes as zip files that can be extracted and added to PATH.

## Files to Create

### 1. `src/core/php_install.rs` (NEW - ~200 lines)
Pattern: Follow `go_install.rs` / `python_install.rs`

```rust
pub struct PhpDownloader {
    base: BaseInstaller,
}

// Functions to implement:
pub fn new() -> Result<Self>
pub fn get_install_dir(&self, version: &str) -> PathBuf
pub fn get_bin_path(&self, version: &str) -> Result<PathBuf>
pub fn list_installed(&self) -> Result<Vec<String>>
pub fn fetch_php_release_versions() -> Result<Vec<String>>
pub fn resolve_php_version_spec(spec: &str, available: &[String]) -> Result<String>
pub fn install_php(downloader: &PhpDownloader, version: &str) -> Result<()>
```

**Download URL (Windows)**:
```
https://downloads.php.net/~windows/releases/archives/php-{VERSION}-nts-Win32-vs17-x64.zip
```

**Security**: SHA256 from download page HTML

## PHP-Specific Details

### Version Resolution
- `"latest"` → highest stable (8.5.7)
- `"8.3"` → highest 8.3.x
- `"8.3.12"` → exact version

### Environment Variables
- `PATH`: Prepend `~/.ven/php/{version}/`
- `PHPRC`: Set to `~/.ven/php/{version}/`

### Smoke Test
```bash
php --version
```

### Supported Versions
- 8.2 (security-only until Dec 2026)
- 8.3 (security-only until Dec 2027)
- 8.4 (active until Dec 2026)
- 8.5 (active until Dec 2027) — latest
