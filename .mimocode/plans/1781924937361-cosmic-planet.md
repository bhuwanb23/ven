# Project Understanding: ven

## What is ven?
**ven** is an intelligent, multi-language version and dependency manager written in Rust (v0.2.1). It supports 8 languages: Node.js, Bun, Python, Ruby, Java, Deno, Go, and Rust. Key feature: predictive dependency analysis that simulates changes before installing.

## Project Structure
- **3 binaries**: `ven` (CLI), `ven-launcher` (portable), `ven-setup` (installer)
- **94+ source files** across 6 modules: CLI (27+), Core (33), Plugins (10), Intelligence (10), Shell (2), Launcher (7), Setup (7+)
- **Website**: `ven_website/` (Next.js)
- **Promo video**: `ven_promo_v2/` (HyperFrames)
