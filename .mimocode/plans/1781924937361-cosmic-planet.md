## Part 2: Add PHP as New Language

### Why PHP?
- **Most requested**: 342 votes (highest on website)
- **Available as zip**: windows.php.net provides zip downloads
- **Simple extraction**: Just extract zip, add to PATH
- **Huge ecosystem**: Composer, Laravel, WordPress, etc.

### How PHP Distribution Works
1. Download zip from `windows.php.net/downloads/releases/`
2. Extract to `~/.ven/php/<version>/`
3. Add to PATH
4. Include: `php.exe`, `php-cgi.exe`, `composer.bat` (if bundled)

### PHP Version Resolution
- `"latest"` → highest stable version
- `"8.3"` → highest 8.3.x
- `"8.3.12"` → exact version

### Download Source
- Windows: `https://windows.php.net/downloads/releases/php-{version}-Win32-{arch}-vs16-x64.zip`
- macOS/Linux: `https://www.php.net/distributions/php-{version}.tar.gz` (needs compilation)
