## Changelog Content for v0.2.4

**New:**
- `ven install php` — install PHP 8.x runtimes from php.net
- `ven add` / `ven remove` / `ven upgrade` for PHP (Composer)
- `ven scan --ghosts` detects PHP `use` statements
- `ven check --eol` reports PHP end-of-life status
- `ven docs` for PHP/Composer packages

**Improved:**
- ven now manages **9** language runtimes (was 8)
