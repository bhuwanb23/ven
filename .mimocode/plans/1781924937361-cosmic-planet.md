## Part 2: Add PHP Support

### Why PHP?
- **Most requested**: 342 votes on ven website (highest)
- **Available as zip**: windows.php.net provides zip downloads
- **Simple extraction**: Extract zip → add to PATH
- **Huge ecosystem**: Composer, Laravel, WordPress, Drupal, etc.
- **Cross-platform**: Windows (zip), Linux/macOS (static-php or compile)

### PHP Distribution Details

| Platform | Format | URL Pattern |
|----------|--------|-------------|
| Windows x64 | ZIP | `https://downloads.php.net/~windows/releases/archives/php-{VERSION}-nts-Win32-vs17-x64.zip` |
| Windows x86 | ZIP | `https://downloads.php.net/~windows/releases/archives/php-{VERSION}-nts-Win32-vs17-x86.zip` |
| Linux/macOS | tar.gz | `https://www.php.net/distributions/php-{VERSION}.tar.gz` (source) |

**Current stable**: PHP 8.5.7 (June 2026)
**Supported versions**: 8.2, 8.3, 8.4, 8.5

### Security Considerations

1. **SHA256 Checksums**: Available on download page HTML (not separate files)
2. **GPG Signatures**: Available for source releases
3. **NTS vs TS**: Use NTS (Non-Thread Safe) for CLI — simpler, no thread safety overhead
4. **Binary verification**: SHA256 before extraction

### PHP-Specific Details

#### Download URL Construction
```rust
fn php_download_url(version: &str, arch: &str) -> String {
    format!(
        "https://downloads.php.net/~windows/releases/archives/php-{}-nts-Win32-vs17-{}.zip",
        version, arch
    )
}
```

#### Environment Variables
- `PATH`: Prepend `~/.ven/php/{version}/`
- `PHPRC`: Set to `~/.ven/php/{version}/` (for php.ini location)

#### Version Resolution
- `"latest"` → highest stable version
- `"8.3"` → highest 8.3.x
- `"8.3.12"` → exact version

#### Smoke Test
```bash
php --version
# Should output: PHP 8.5.7 (cli) (built: Jun 2 2026 ...)
```

## Part 3: Future Languages (Research Complete)

| Language | Difficulty | Notes |
|----------|------------|-------|
| **Zig** | EASY | Official zip, JSON API with SHA256, perfect fit |
| **Lua** | EASY | Tiny binaries, but third-party distribution |
| **.NET** | MODERATE | Official zip exists, but large (200-400 MiB) |
| **Swift** | HARD | No zip for Windows, requires VS prerequisites |
| **Kotlin** | VERY HARD | Requires JVM, not standalone |
| **Elixir** | HARD | Requires BEAM (Erlang), not standalone |
| **Scala** | HARD | Requires JVM, not standalone |

**Recommendation**: After PHP, add Zig next (easiest, perfect fit for zip-extract-PATH model).
